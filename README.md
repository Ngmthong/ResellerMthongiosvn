# Mthongiosvn Website

Website tĩnh, dùng một file `index.html` (HTML + CSS + SVG tích hợp sẵn). Không cần cài thư viện hoặc tải thêm ảnh.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload `index.html` và `README.md` lên thư mục gốc của repository.
3. Mở **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main` và folder `/(root)`, nhấn **Save**.
6. Đợi GitHub Pages xuất bản website; URL sẽ hiển thị trong mục Pages.

## Cập nhật website
Sửa file `index.html`, sau đó upload/commit phiên bản mới lên repository.
